## Kylaq relevance
SSP 111 documents engine code **CHZD** (Karoq/Octavia-era, 200 Nm). The Kylaq 1.0 TSI is the
**evo** variant: same 999 cm³ architecture, **178 Nm @ 1750–4000 rpm** (app PowertrainModel pin —
do NOT swap to 200 Nm). Hardware family facts below apply to both; torque figure does not.

## Engine parameters (CHZD)
| Parameter | Value |
|---|---|
| Design | Transverse 3-cyl spark-ignition, DI, turbo, liquid-cooled, DOHC in camshaft case, toothed-belt valvetrain |
| Displacement / bore / stroke | 999 cm³ / 74.5 mm / 76.4 mm |
| Valves | 4 per cylinder (12 total), roller finger followers w/ backlash compensation |
| Max power | 85 kW @ 5000–5500 rpm |
| Max torque | 200 Nm @ 2000–3500 rpm (Kylaq evo: 178 Nm @ 1750–4000) |
| Compression | 10.5 : 1 |
| Cam adjustment | intake 50° crank, exhaust 40° crank |
| Weight | **78 kg** (aluminium block, no balance shaft) |
| Fuel | unleaded, min RON 95 |
| Emissions | EU6 |

## Key hardware (with VAG component designators — useful for DVC/PID context)
- **Intake:** compact system — air filter, turbo, throttle valve control unit **GX3**, plastic
  intake manifold with **integrated air-water intercooler** (own coolant circuit, short charge
  path → fast boost rise). Senders: **GX26 = G31 (charge pressure) + G42 (intake air temp)**
  upstream of throttle; **GX9 = G71 (manifold pressure) + G299 (air temp 2)** post-intercooler.
- **Camshafts:** housed in a non-disassemblable aluminium **camshaft case** (4 bearings);
  adjustment valves **N205** (intake) / **N318** (exhaust); Hall senders **G40** (intake) /
  **G300** (exhaust). Coolant pump belt-driven off the exhaust camshaft; cooling regulator case
  with integrated pump; block and head have two independent cooling circuits.
- **Block:** aluminium open-deck pressure casting (no sand core); grey cast-iron liners, rough
  outer finish, honed → minimal deformation, reduced ring pre-tension.
- **Crank train:** forged steel crankshaft, 4 main bearings (ø45 mm), 4 counterweights;
  fracture-split con-rod big ends (ø47.8 mm); **hollow gudgeon pins with hard-carbon (DLC-class)
  coating**; bush-free small ends (rolling-hardened); piston crown recesses; **first main bearing
  has a polymer coating for Start-Stop duty**.
- **Balancing:** no balance shaft — vibration damper + flywheel carry deliberate, model-specific
  imbalances acting against each other. Damper/pulley joined by an **uncoded Hirth coupling** —
  TDC marks on damper groove and belt cover MUST be aligned at fitment (engine at cyl-1 TDC);
  flywheel has one irregular bolt hole (foolproof).
- **High-pressure fuel:** first EA211 with **120–250 bar** variable injection pressure; HP pump
  with regulator valve **N276**; stainless rail; **5-hole injectors N30–N32**; rail pressure
  sender **G247**; multiple injection strategies (up to 3 injections: start-up, cat warm-up,
  full load ≤3000 rpm).
- **Turbocharger:** relative boost up to **1.6 bar**; **electronic charging-pressure regulator —
  electric wastegate actuator V465 with integrated position sender**; cast-steel housing rated to
  **1050 °C** EGT; coolant connections; optimised turbine inflow angle for fast spool. FOD rule:
  after any mechanical turbo damage, inspect filter/ducts/intercooler for foreign objects —
  replace intercooler if contaminated, else repeat failure.
- **Oil system:** **continuous oil-pressure regulation 1.3–3.3 bar** (vs two-stage on 1.4 TSI):
  rotary **vane pump with eccentric control ring**, driven directly off the crankshaft; PWM-driven
  **oil pressure regulator valve N428** rotates the control ring against a spring (less ring
  rotation = more delivery). On start-up the spring holds full delivery for fastest pressure
  build-up; failsafe = maximum delivery without electrical signal. Oil pressure sender **G10**.
  Benefits: lower pump input power (city/highway loads), less friction, less oil aeration/aging.

## App cross-checks
- PowertrainModel constants stay on Kylaq evo figures: 85 kW, **178 Nm** plateau, tip-in 800 ms.
- Learning-guide content: electric wastegate (fast boost control — explains minimal lag above
  ~2000 rpm and why sub-2000 response is cam/boost-build limited), 250 bar DI, 1.3–3.3 bar
  variable oil pressure, 78 kg block, integrated intercooler rationale, TDC-mark damper caution
  (any workshop touching the crank must align Hirth coupling marks).
- Sensor designators above map to the app's PID/DTC explorer copy where relevant (G71 = PID 010B
  MAP source, G42/G299 intake temps, G247 fuel rail pressure for extended PIDs).
